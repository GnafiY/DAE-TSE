# DAE-TSE Libri2Mix Recipe

- `run.sh`: prepare training lists/resources, whole-utterance backbone training,
  and evaluation with the original four-keyword protocol.
- `infer.sh`: the existing paper checkpoint inference entry.
- `confs/dae-bsrnn.yaml`: the original backbone architecture and training setup.

See the [training guide](../../../README.md#stage-b-train-the-whole-utterance-tse-backbone)
and [paper inference instructions](../../../README.md#inference).
